# 家族の思い出マップ — 参加ガイド

ぐっちが作っている家族専用の地図 + スケジュール + メモ共有アプリ「家族の思い出」に参加する手順です。スマホ（iPhone）で 5 分くらいで終わります。

---

## 1. URL を Safari で開く

iPhone の **Safari** で以下を開いてください。

```
https://examrx79bd03-star.github.io/25t-tracker/family-map/
```

（Chrome や他のブラウザではなく **Safari** で開くのがポイントです。あとで「ホーム画面に追加」するときに Safari が必要なので）

---

## 2. 新規登録

「ログイン / 新規登録」の画面が出ます。

1. 上のタブで **「新規登録」** を選択
2. メールアドレスを入力（普段使っているもので OK）
3. パスワードを設定（**6 文字以上**）
4. パスワードをもう一度入力（確認用）
5. 「アカウントを作成」をタップ

→ アカウントが作成されます。

> ⚠️ **メールアドレスとパスワードは忘れないようにメモしてください**。忘れた場合は「パスワードを忘れた」リンクから再設定メールを送れますが、メールアドレスを忘れると詰みます。

---

## 3. 家族コードを入力

次に「家族コード」を聞かれます。

```
家族コード： VNWMGUF94G
```

このコードを入力 → 「参加」または「接続」をタップ。

→ ぐっちの家族グループに参加した状態になります。

---

## 4. プロフィール設定

「お名前を教えてください」というプロンプトが出ます。

1. **表示名**：家族の中で呼ばれている名前（例：「ママ」「あいちゃん」など）
2. **アイコン**：3 種類から選択
   - **文字**（名前の頭文字を表示）
   - **絵文字**（好きな絵文字を 1 つ）
   - **色のみ**（色だけのまる）
3. **背景色**：12 色から好きな色を選択
4. プレビューで自分のアバターを確認
5. 「保存して始める」をタップ

→ プロフィールが保存され、地図画面に切り替わります。

> あとから変更したくなったら、画面右上の歯車アイコン → 「マイプロフィール」から編集できます。

---

## 5. ホーム画面に追加（PWA 化）

毎回 Safari で URL を入力するのは面倒なので、**ホーム画面にアイコンを追加**します。

1. Safari 下部の **共有ボタン**（□に上向き矢印のアイコン）をタップ
2. メニューを下にスクロール → **「ホーム画面に追加」** をタップ
3. 名前を確認（「家族の思い出」のままで OK）→ 「追加」をタップ

→ iPhone のホーム画面に「家族の思い出」アイコンが追加されます。

以降はホーム画面のアイコンをタップするだけで起動できます。**ログイン状態は自動で保持される**ので、毎回パスワードを入力する必要はありません。

> ⚠️ **重要：ホーム画面のアイコンを削除しないでください**。削除するとログイン情報も一緒に消えて、再ログインが必要になります（再ログイン自体は可能ですが、過去のデータとの紐付けが面倒なことになるリスクがあります）。

---

## 6. パスワードを忘れたら

ログイン画面で：

1. 「ログイン」タブを選択
2. メールアドレスを入力
3. 下の **「パスワードを忘れた」** リンクをタップ
4. 「パスワード再設定メールを送信しました」と出る
5. メールを開いて、リンクから新しいパスワードを設定
6. 戻ってきて新しいパスワードでログイン

---

## トラブルが起きたら

ぐっちに連絡してください。よくあるパターン：

- **「メールアドレスは既に使われています」と出る**：そのメールアドレスで既にアカウントが作成済み。「ログイン」タブで同じメールとパスワードを使う
- **家族コードを入れても参加できない**：コードのスペルを再確認（半角英大文字）、もしくは家族コードが変更されていないか ぐっちに確認
- **アプリが起動しない / 白い画面のまま**：
  - 「設定 → Safari → 履歴と Web サイトデータを消去」を試す
  - **ホーム画面のアイコンは削除しない**（削除するとデータが消える可能性があります）
- **過去の予定の「作成者」が違う人になっている**：ぐっち側でデータ復旧スクリプトを動かす必要があります（`_scripts/migrate-uids.mjs` 参照、家族メンバー側では何もできない）
