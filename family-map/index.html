Google Maps からインポート

奥さん（や別アカウント）の Google Maps に保存してある「行きたい場所」「お気に入り」「保存済み」リストを、CSVファイル経由でこのアプリに取り込みます。

📱 iPhoneでの手順（タップで開閉）
  1. Safari で takeout.google.com を開く
  2. 取り込みたいリストを持っている Google アカウントでログイン
    （既に別アカウントでログインしている場合は右上のアイコン→アカウント切り替え）
  3. 画面上の 「選択をすべて解除」 をタップ
  4. スクロールして 「マップ（マイプレイス）」 だけにチェックを入れる
    （「マップ」と「マップ（マイプレイス）」は別物。「マイプレイス」付きの方）
  5. 一番下まで → 「次のステップ」
  6. 配信方法： メールでリンクを送信 / ファイル形式： .zip / 頻度： 1 回限り のまま → 「エクスポートを作成」
  7. 数分〜1時間後、Google から 「エクスポートをご利用いただけます」 というメールが届く
    （届かない場合は迷惑メールも確認）
  8. メール内の 「ファイルをダウンロード」 ボタンをタップ → 再度パスワード確認 → ダウンロード開始
  9. iPhone 上部に ↓ マーク が出てくる → タップ → ダウンロードが完了 するまで待つ
  10. 「ファイル」 アプリ（青いフォルダのアイコン）を開く → 左下 「ブラウズ」 → 「ダウンロード」 フォルダ
  11. そこにある takeout-XXXXXXX.zip を 長押し → 「展開」
  12. 展開された Takeout フォルダ → マップ（マイプレイス） → 保存済みの場所.csv や 行きたい場所.csv 等 が複数ある
  13. このアプリに戻り、下の 「CSV を選択」 をタップ → ファイルアプリから対象の CSV を選択
    （複数選択可）

✓ CSV を選んだあと、ファイルごとにステータスを選択できます
✓ 既に同じ場所のピンがある場合は 自動スキップ
✓ Places API で店舗詳細（住所・口コミ）も自動取得

取り込む CSV と、それぞれを 行きたい / 訪問済み / 思い出 のどれで登録するか選んでください。
ファイル名から自動で推測してありますが、必要なら変えてOKです。
